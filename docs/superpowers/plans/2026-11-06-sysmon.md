# sysmon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local RAM and process monitor with a browser sidebar that renders Claude's kill plan behind an Optimize button.

**Architecture:** A Python daemon thread samples processes via `psutil` into a 15 minute ring buffer and writes `data/snapshot.json` atomically. Claude Code reads that file directly and writes `data/advice.json`, which the browser polls. A stdlib `ThreadingHTTPServer` bound to loopback serves the page and is the only component with authority to kill anything.

**Tech Stack:** Python 3.14, `psutil` 7.2.2, stdlib `http.server`, vanilla HTML/CSS/JS, pytest 9.2.0.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-11-06-sysmon-design.md`. Every requirement there applies.
- Project root: `C:\Users\User\Documents\code\sysmon`. All paths below are relative to it.
- No new runtime dependencies. `psutil` and the Python stdlib only. pytest is dev-only.
- Server binds `127.0.0.1` exclusively. Never `0.0.0.0`, never a LAN address.
- A kill target is always a `(pid, create_time)` pair. A bare PID is never sufficient to authorize a kill.
- `safety.py` and `analysis.py` are pure. No I/O, no psutil calls, no globals. They take data and return data.
- Every write to `data/*.json` is atomic: write `<name>.tmp`, then `os.replace`.
- Sample interval 2.0 seconds. Ring buffer 450 samples, which is 15 minutes.
- Idle threshold is `cpu_percent > 1.0`. Growth flag is above 5 MB/min sustained 5 minutes.
- Run tests with `python -m pytest` from the project root.

```python
"""Pure derived facts over sampled process data.

No I/O, no psutil, no globals. Everything here takes data and returns data,
which is what makes it testable without a running machine.
"""

from collections import defaultdict

from monitor.constants import (
    GROWTH_MB_PER_MIN,
    GROWTH_MIN_SECONDS,
    IDLE_CPU_THRESHOLD,
)

_BYTES_PER_MB = 1024 * 1024


def idle_seconds(series, interval):
    """Seconds since the last sample where CPU was above the idle threshold.

    A series that was never busy returns the full window, which is the
    honest answer: idle for at least as long as we have been watching.
    """
    if not series:
        return 0.0
    for offset, entry in enumerate(reversed(series)):
        if entry.get("cpu_percent", 0.0) > IDLE_CPU_THRESHOLD:
            return offset * interval
    return len(series) * interval


def rss_trend_mb_per_min(series, interval):
    """Least-squares slope of RSS, in MB per minute."""
    n = len(series)
    if n < 2:
        return 0.0

    mean_x = (n - 1) / 2.0
    ys = [entry.get("rss", 0) for entry in series]
    mean_y = sum(ys) / n

    numerator = sum((i - mean_x) * (y - mean_y) for i, y in enumerate(ys))
    denominator = sum((i - mean_x) ** 2 for i in range(n))
    if denominator == 0:
        return 0.0

    bytes_per_sample = numerator / denominator
    return (bytes_per_sample / _BYTES_PER_MB) * (60.0 / interval)


def is_growing(series, interval):
    """True when RSS has climbed steadily for long enough to mean something.

    The duration floor matters. Any app allocates fast during its first few
    seconds, and flagging that as a leak would make the signal useless.
    """
    if len(series) * interval < GROWTH_MIN_SECONDS:
        return False
    return rss_trend_mb_per_min(series, interval) > GROWTH_MB_PER_MIN


def group_processes(sample):
    """One row per executable, summed. Chrome is a dozen processes."""
    buckets = defaultdict(
        lambda: {"rss": 0, "cpu_percent": 0.0, "pids": [], "members": []}
    )
    for proc in sample:
        key = proc.get("name", "").lower()
        bucket = buckets[key]
        bucket["rss"] += proc.get("rss", 0)
        bucket["cpu_percent"] += proc.get("cpu_percent", 0.0)
        bucket["pids"].append(proc.get("pid"))
        bucket["members"].append(proc)

    groups = []
    for name, bucket in buckets.items():
        groups.append(
            {
                "name": name,
                "rss": bucket["rss"],
                "cpu_percent": round(bucket["cpu_percent"], 1),
                "count": len(bucket["pids"]),
                "pids": bucket["pids"],
                "members": bucket["members"],
            }
        )
    groups.sort(key=lambda g: g["rss"], reverse=True)
    return groups


def build_facts(buffer, totals, interval):
    """Combine the newest sample with per-group history from the whole buffer."""
    if not buffer:
        return {
            "groups": [],
            "totals": totals,
            "sample_count": 0,
            "window_seconds": 0.0,
        }

    latest = buffer[-1]
    groups = group_processes(latest)

    # Per-group history: sum RSS and CPU across that group's processes in
    # every past sample, so the trend follows the app rather than one PID.
    for group in groups:
        name = group["name"]
        history = []
        for sample in buffer:
            rss = 0
            cpu = 0.0
            for proc in sample:
                if proc.get("name", "").lower() == name:
                    rss += proc.get("rss", 0)
                    cpu += proc.get("cpu_percent", 0.0)
            history.append({"rss": rss, "cpu_percent": cpu})
        group["idle_seconds"] = idle_seconds(history, interval)
        group["rss_trend"] = round(rss_trend_mb_per_min(history, interval), 2)
        group["growing"] = is_growing(history, interval)

    return {
        "groups": groups,
        "totals": totals,
        "sample_count": len(buffer),
        "window_seconds": len(buffer) * interval,
    }
```

Create `monitor/safety.py`:

```python
"""Kill authorization. Pure, and the unit that matters most.

The browser is a view with no authority. Every kill request is revalidated
here against the live snapshot, so a stale page, a crafted POST and a
hand-edited advice.json all hit the same four checks.
"""

from monitor.constants import BLOCKED_NAMES, BLOCKED_PIDS


def protected_pids(own_pid, ancestor_pids):
    """PIDs that must never be killed, whatever anyone asks.

    The ancestor chain is what stops Optimize killing the terminal the user
    is talking to Claude through, since the monitor is started from it.
    """
    return frozenset({own_pid, *ancestor_pids, *BLOCKED_PIDS})


def check_target(target, snapshot, protected):
    """Return (allowed, reason) for one kill target."""
    pid = target.get("pid")
    if not isinstance(pid, int) or isinstance(pid, bool):
        return False, "pid is not an integer"

    if pid in protected:
        return False, f"pid {pid} is protected, it runs this tool or its session"

    create_time = target.get("create_time")
    if create_time is None:
        return False, "target has no create_time, refusing on identity grounds"

    match = None
    for proc in snapshot:
        if proc.get("pid") == pid:
            match = proc
            break
    if match is None:
        return False, f"pid {pid} is not in the current snapshot"

    if match.get("name", "").lower() in BLOCKED_NAMES:
        return False, f"{match.get('name')} is system-critical and cannot be killed"

    if match.get("create_time") != create_time:
        return False, f"pid {pid} changed since the page loaded, refresh and retry"

    return True, "ok"


def filter_targets(targets, snapshot, protected):
    """Split targets into (allowed snapshot processes, rejected with reasons)."""
    allowed = []
    rejected = []
    for target in targets:
        ok, reason = check_target(target, snapshot, protected)
        if not ok:
            rejected.append({**target, "reason": reason})
            continue
        for proc in snapshot:
            if proc.get("pid") == target.get("pid"):
                allowed.append(proc)
                break
    return allowed, rejected
```

```python
        "available": False,
        "summary": "",
        "targets": [],
        "notes": "",
        "written_at": "",
```

Create `monitor/sampler.py`:

```python
"""Samples the process table on a daemon thread into a ring buffer.

The persistent `_procs` cache is load-bearing. psutil reports cpu_percent
as the change since the previous call on the same Process object, so
rebuilding those objects each pass would report 0.0 forever and idle
detection would never fire.
"""

import json
import os
import threading
import time
from collections import deque

import psutil

from monitor import analysis
from monitor.constants import (
    BUFFER_DEPTH,
    DATA_DIR,
    SAMPLE_INTERVAL,
    SNAPSHOT_PATH,
)

_FIELDS = ["pid", "name", "memory_info", "cpu_percent", "create_time", "username"]


class Sampler:
    def __init__(self, interval=SAMPLE_INTERVAL, depth=BUFFER_DEPTH):
        self.interval = interval
        self._buffer = deque(maxlen=depth)
        self._procs = {}
        self._totals = {}
        self._lock = threading.Lock()
        self._stop = threading.Event()
        self._thread = None

    def start(self):
        self.sample()  # prime cpu_percent and give the first request data
        self._thread = threading.Thread(target=self._loop, daemon=True)
        self._thread.start()

    def stop(self):
        self._stop.set()

    def _loop(self):
        while not self._stop.wait(self.interval):
            try:
                self.sample()
            except Exception:
                # A sampling failure must not kill the thread. The next
                # pass will almost always succeed.
                continue

    def sample(self):
        seen = set()
        rows = []
        for proc in psutil.process_iter(_FIELDS):
            try:
                info = proc.info
                pid = info["pid"]
                seen.add(pid)
                cached = self._procs.get(pid)
                if cached is None or cached.create_time() != info["create_time"]:
                    cached = proc
                    self._procs[pid] = proc
                    cpu = 0.0
                else:
                    cpu = cached.cpu_percent(None)
                mem = info["memory_info"]
                rows.append(
                    {
                        "pid": pid,
                        "name": info["name"] or "",
                        "rss": mem.rss if mem else 0,
                        "cpu_percent": round(cpu, 1),
                        "create_time": info["create_time"],
                        "username": info["username"] or "",
                        "access": True,
                    }
                )
            except psutil.NoSuchProcess:
                continue
            except psutil.AccessDenied:
                rows.append(
                    {
                        "pid": proc.pid,
                        "name": _safe_name(proc),
                        "rss": 0,
                        "cpu_percent": 0.0,
                        "create_time": None,
                        "username": "",
                        "access": False,
                    }
                )
            except Exception:
                continue

        for pid in list(self._procs):
            if pid not in seen:
                del self._procs[pid]

        vm = psutil.virtual_memory()
        totals = {
            "ram_total": vm.total,
            "ram_used": vm.used,
            "ram_available": vm.available,
            "ram_percent": vm.percent,
            "cpu_percent": psutil.cpu_percent(None),
            "sampled_at": time.time(),
        }

        with self._lock:
            self._buffer.append(rows)
            self._totals = totals

        self._write_snapshot(rows, totals)
        return rows

    def _write_snapshot(self, rows, totals):
        """Atomic write, so Claude never reads a half-written file."""
        DATA_DIR.mkdir(parents=True, exist_ok=True)
        payload = {
            "sampled_at": totals["sampled_at"],
            "totals": totals,
            "facts": self.facts(),
        }
        tmp = SNAPSHOT_PATH.with_suffix(".tmp")
        tmp.write_text(json.dumps(payload, indent=2, default=str), encoding="utf-8")
        os.replace(tmp, SNAPSHOT_PATH)

    def latest(self):
        with self._lock:
            return list(self._buffer[-1]) if self._buffer else []

    def buffer_list(self):
        with self._lock:
            return [list(sample) for sample in self._buffer]

    def totals(self):
        with self._lock:
            return dict(self._totals)

    def facts(self):
        facts = analysis.build_facts(self.buffer_list(), self.totals(), self.interval)
        # members carry no information the UI needs and triple the payload
        for group in facts["groups"]:
            group.pop("members", None)
        return facts

    def own_context(self):
        """Our PID and every ancestor, for the self-protection check."""
        me = psutil.Process()
        ancestors = []
        for parent in me.parents():
            try:
                ancestors.append(parent.pid)
            except psutil.Error:
                continue
        return me.pid, ancestors


def _safe_name(proc):
    try:
        return proc.name()
    except psutil.Error:
        return f"pid {proc.pid}"
```

Create `monitor/killer.py`:

```python
"""Closes processes, waits, and reports honestly on what refused.

The graceful path shells to `taskkill` without /F on purpose.
psutil's terminate() calls TerminateProcess on Windows, which is immediate
and unconditional, so it would destroy unsaved work with no prompt.
taskkill without /F posts WM_CLOSE, which lets an app show its own save
dialog and refuse to die. That refusal is a feature here, not an error.
"""

import subprocess
import time

import psutil

from monitor.constants import GRACEFUL_WAIT_SECONDS

_NO_WINDOW = getattr(subprocess, "CREATE_NO_WINDOW", 0)


def _run_taskkill(pid, force):
    cmd = ["taskkill", "/PID", str(int(pid))]
    if force:
        cmd.insert(1, "/F")
    try:
        completed = subprocess.run(
            cmd,
            capture_output=True,
            text=True,
            timeout=10,
            creationflags=_NO_WINDOW,
        )
    except (subprocess.SubprocessError, OSError) as exc:
        return False, str(exc)
    output = (completed.stdout or "") + (completed.stderr or "")
    return completed.returncode == 0, output.strip()


def _gone(pid, create_time):
    """True when that exact process is no longer running.

    The create_time comparison matters: Windows recycles PIDs, so
    pid_exists alone can report a brand new process as the old one.
    """
    try:
        proc = psutil.Process(pid)
        if create_time is not None and proc.create_time() != create_time:
            return True
        return proc.status() == psutil.STATUS_ZOMBIE
    except (psutil.NoSuchProcess, psutil.AccessDenied):
        return True


def kill_targets(procs, force=False, wait=GRACEFUL_WAIT_SECONDS):
    """Close each process, then report what actually happened."""
    results = []
    issued = []

    for proc in procs:
        pid = proc.get("pid")
        create_time = proc.get("create_time")
        if _gone(pid, create_time):
            results.append(_result(proc, "closed", proc.get("rss", 0), "already gone"))
            continue
        ok, detail = _run_taskkill(pid, force)
        issued.append((proc, ok, detail))

    deadline = time.monotonic() + wait
    pending = list(issued)
    while pending and time.monotonic() < deadline:
        still = []
        for entry in pending:
            proc, ok, detail = entry
            if _gone(proc.get("pid"), proc.get("create_time")):
                results.append(
                    _result(proc, "closed", proc.get("rss", 0), "closed on request")
                )
            else:
                still.append(entry)
        pending = still
        if pending:
            time.sleep(0.25)

    for proc, ok, detail in pending:
        status = "refused" if ok else "failed"
        note = (
            "still running, it may be asking you to save"
            if ok
            else detail or "taskkill reported an error"
        )
        results.append(_result(proc, status, 0, note))

    return results


def _result(proc, status, freed, detail):
    return {
        "pid": proc.get("pid"),
        "name": proc.get("name", ""),
        "status": status,
        "freed_bytes": freed,
        "detail": detail,
    }
```

```python
Bound to loopback on purpose. A kill endpoint reachable from the network
is not a monitoring tool.

import sys

from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer

from monitor import killer, safety
from monitor.advice import read_advice
from monitor.constants import (
    ADVICE_PATH,
    BLOCKED_NAMES,
    BLOCKED_PIDS,
    HOST,
    PORT,
    WEB_DIR,

from monitor.sampler import Sampler

MAX_TARGETS = 64

_STATIC = {
    "/": ("index.html", "text/html; charset=utf-8"),
    "/index.html": ("index.html", "text/html; charset=utf-8"),
    "/style.css": ("style.css", "text/css; charset=utf-8"),
    "/app.js": ("app.js", "text/javascript; charset=utf-8"),

def build_state(sampler, advice_path=ADVICE_PATH):
    """Everything the page needs in one response."""
    facts = sampler.facts()
    protected_names = BLOCKED_NAMES

    for group in facts["groups"]:
        blocked = group["name"] in protected_names
        has_pid_block = any(pid in BLOCKED_PIDS for pid in group.get("pids", []))
        group["killable"] = not (blocked or has_pid_block)

    facts["advice"] = read_advice(advice_path)
    return facts


def handle_kill(payload, sampler, protected):
    """Revalidate every target, then act. The page has no authority here."""
    if not isinstance(payload, dict):
        return {"ok": False, "error": "body must be a JSON object"}

    targets = payload.get("targets")
    if not isinstance(targets, list):
        return {"ok": False, "error": "targets must be a list"}
    if len(targets) > MAX_TARGETS:
        return {"ok": False, "error": f"at most {MAX_TARGETS} targets per request"}
    if not all(isinstance(t, dict) for t in targets):
        return {"ok": False, "error": "each target must be an object"}

    force = bool(payload.get("force"))
    snapshot = sampler.latest()
    allowed, rejected = safety.filter_targets(targets, snapshot, protected)
    results = killer.kill_targets(allowed, force=force)
    return {"ok": True, "results": results, "rejected": rejected}


class Handler(BaseHTTPRequestHandler):
    sampler = None
    protected = frozenset()

    def log_message(self, fmt, *args):
        pass  # the console is for startup and errors, not a request log

    def _send(self, code, body, content_type="application/json"):
        data = body if isinstance(body, bytes) else body.encode("utf-8")
        self.send_response(code)
        self.send_header("Content-Type", content_type)
        self.send_header("Content-Length", str(len(data)))
        self.send_header("Cache-Control", "no-store")
        self.end_headers()
        self.wfile.write(data)

    def _send_json(self, code, obj):
        self._send(code, json.dumps(obj, default=str))

    def do_GET(self):
        path = self.path.split("?")[0]
        if path in _STATIC:
            name, content_type = _STATIC[path]
            try:
                self._send(200, (WEB_DIR / name).read_bytes(), content_type)
            except OSError:
                self._send_json(500, {"error": f"{name} is missing"})
            return
        if path == "/api/state":
            self._send_json(200, build_state(self.sampler))
            return
        if path == "/api/snapshot":
            self._send_json(200, {"processes": self.sampler.latest()})
            return
        self._send_json(404, {"error": "not found"})

    def do_POST(self):
        if self.path.split("?")[0] != "/api/kill":
            self._send_json(404, {"error": "not found"})
            return
        try:
            length = int(self.headers.get("Content-Length") or 0)
        except ValueError:
            self._send_json(400, {"ok": False, "error": "bad Content-Length"})
            return
        if length <= 0 or length > 100_000:
            self._send_json(400, {"ok": False, "error": "bad body size"})
            return
        try:
            payload = json.loads(self.rfile.read(length).decode("utf-8"))
        except (ValueError, UnicodeDecodeError) as exc:
            self._send_json(400, {"ok": False, "error": f"bad JSON: {exc}"})
            return

        result = handle_kill(payload, self.sampler, self.protected)
        self._send_json(200 if result.get("ok") else 400, result)


def make_server(sampler):
    own_pid, ancestors = sampler.own_context()
    Handler.sampler = sampler
    Handler.protected = safety.protected_pids(own_pid, ancestors)
    return ThreadingHTTPServer((HOST, PORT), Handler)


def main():
    sampler = Sampler()
    sampler.start()
    try:
        httpd = make_server(sampler)
    except OSError as exc:
        print(f"Cannot bind {HOST}:{PORT}. {exc}", file=sys.stderr)
        print("Another sysmon may already be running.", file=sys.stderr)
        return 1

    url = f"http://{HOST}:{PORT}/"
    print(f"sysmon running at {url}")
    print(f"Protected PIDs: {sorted(Handler.protected)}")
    print("Press Ctrl+C to stop.")
    webbrowser.open(url)
    try:
        httpd.serve_forever()
    except KeyboardInterrupt:
        print("\nstopping")
    finally:
        sampler.stop()
        httpd.server_close()
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```javascript
'use strict';

const POLL_MS = 2000;
const state = { groups: [], procs: [], advice: null, checked: new Set(), touched: false };

const $ = (id) => document.getElementById(id);

function mb(bytes) {
  const m = bytes / 1048576;
  return m >= 1024 ? `${(m / 1024).toFixed(1)} GB` : `${Math.round(m)} MB`;
}

function idleText(seconds) {
  if (seconds < 60) return `${Math.round(seconds)}s`;
  return `${Math.round(seconds / 60)}m`;
}

async function poll() {
  try {
    const [stateRes, snapRes] = await Promise.all([
      fetch('/api/state'),
      fetch('/api/snapshot'),
    ]);
    const data = await stateRes.json();
    const snap = await snapRes.json();
    state.groups = data.groups || [];
    state.procs = snap.processes || [];
    state.advice = data.advice || null;
    applyAdvice();
    render(data);
  } catch (err) {
    $('advice-body').textContent = `Lost contact with the monitor: ${err.message}`;
  }
}

// Claude's targets arrive pre-ticked, but only until the user touches a
// checkbox. After that their selection wins, so a poll never undoes a click.
function applyAdvice() {
  if (state.touched || !state.advice || !state.advice.available) return;
  const names = new Set();
  for (const target of state.advice.targets || []) {
    const match = state.procs.find((p) => p.pid === target.pid);
    if (match) names.add(match.name.toLowerCase());
    else if (target.name) names.add(String(target.name).toLowerCase());
  }
  state.checked = names;
}

function render(data) {
  const totals = data.totals || {};
  const ram = totals.ram_percent || 0;
  $('ram-value').textContent = `${mb(totals.ram_used || 0)} / ${mb(totals.ram_total || 0)}  ${ram.toFixed(0)}%`;
  $('ram-bar').style.width = `${ram}%`;
  $('ram-bar').classList.toggle('high', ram >= 85);

  const cpu = totals.cpu_percent || 0;
  $('cpu-value').textContent = `${cpu.toFixed(0)}%`;
  $('cpu-bar').style.width = `${Math.min(cpu, 100)}%`;

  $('proc-count').textContent = `${state.groups.length} apps`;
  $('window-info').textContent =
    `${data.sample_count || 0} samples over ${Math.round((data.window_seconds || 0) / 60)} min`;

  renderList();
  renderTrend();
  renderAdvice();
}

function renderList() {
  const list = $('process-list');
  list.innerHTML = '';
  const suggested = new Set(state.checked);

  for (const group of state.groups.slice(0, 40)) {
    const row = document.createElement('div');
    row.className = 'row';
    if (!group.killable) row.classList.add('blocked');
    if (suggested.has(group.name) && group.killable) row.classList.add('suggested');

    const box = document.createElement('input');
    box.type = 'checkbox';
    box.disabled = !group.killable;
    box.checked = group.killable && state.checked.has(group.name);
    box.addEventListener('change', () => {
      state.touched = true;
      if (box.checked) state.checked.add(group.name);
      else state.checked.delete(group.name);
      renderList();
      updateButton();
    });

    const label = document.createElement('div');
    const name = document.createElement('div');
    name.className = 'row-name';
    name.textContent = group.name;
    const meta = document.createElement('div');
    meta.className = 'row-meta';
    const bits = [];
    if (group.count > 1) bits.push(`${group.count} procs`);
    if (!group.killable) bits.push('system-critical');
    else if (group.idle_seconds > 300) bits.push(`idle ${idleText(group.idle_seconds)}`);
    if (group.growing) bits.push(`+${group.rss_trend} MB/min`);
    meta.textContent = bits.join('  ·  ');
    label.append(name, meta);

    const rss = document.createElement('div');
    rss.className = 'row-rss';
    rss.textContent = mb(group.rss);

    row.append(box, label, rss);
    list.append(row);
  }
  updateButton();
}

function renderTrend() {
  const body = $('trend-body');
  body.innerHTML = '';
  for (const group of state.groups.slice(0, 15)) {
    const tr = document.createElement('tr');
    const tag = group.growing
      ? '<span class="tag growing">growing</span>'
      : group.idle_seconds > 300
        ? '<span class="tag idle">idle</span>'
        : '<span class="tag active">active</span>';
    tr.innerHTML =
      `<td>${escapeHtml(group.name)}</td>` +
      `<td>${mb(group.rss)}</td>` +
      `<td>${group.cpu_percent.toFixed(1)}%</td>` +
      `<td>${idleText(group.idle_seconds)}</td>` +
      `<td>${tag}</td>`;
    body.append(tr);
  }
}

function renderAdvice() {
  const box = $('advice-body');
  const advice = state.advice;
  if (!advice || !advice.available) {
    box.className = 'advice-body muted';
    box.textContent = advice && advice.error
      ? `advice.json could not be read: ${advice.error}`
      : 'No advice yet. Ask Claude to check your laptop.';
    return;
  }
  box.className = 'advice-body';
  box.textContent = advice.summary || 'Claude wrote advice with no summary.';
  if (advice.notes) {
    const note = document.createElement('div');
    note.className = 'advice-note';
    note.textContent = advice.notes;
    box.append(note);
  }
}

function updateButton() {
  const btn = $('optimize');
  const n = selectedTargets().length;
  btn.disabled = n === 0;
  btn.textContent = n === 0 ? 'Optimize' : `Optimize  ·  ${n} processes`;
}

function selectedTargets() {
  const targets = [];
  for (const proc of state.procs) {
    if (!state.checked.has((proc.name || '').toLowerCase())) continue;
    if (proc.create_time === null || proc.create_time === undefined) continue;
    targets.push({ pid: proc.pid, create_time: proc.create_time });
  }
  return targets;
}

async function optimize(targets, force) {
  const btn = $('optimize');
  btn.disabled = true;
  btn.textContent = 'Working...';
  try {
    const res = await fetch('/api/kill', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ targets, force: Boolean(force) }),
    });
    renderResults(await res.json());
  } catch (err) {
    renderResults({ ok: false, error: err.message });
  }
  state.checked.clear();
  state.touched = true;
  await poll();
}

function renderResults(data) {
  const box = $('results');
  box.innerHTML = '';
  if (!data.ok) {
    box.innerHTML = `<div class="result failed">${escapeHtml(data.error || 'request failed')}</div>`;
    return;
  }

  let freed = 0;
  for (const r of data.results || []) {
    if (r.status === 'closed') freed += r.freed_bytes || 0;
    const div = document.createElement('div');
    div.className = `result ${r.status}`;
    const left = document.createElement('span');
    left.textContent = `${r.name} ${r.status}`;
    div.append(left);

    if (r.status === 'refused') {
      const force = document.createElement('button');
      force.className = 'force-btn';
      force.textContent = 'force';
      const proc = state.procs.find((p) => p.pid === r.pid);
      force.addEventListener('click', () =>
        optimize([{ pid: r.pid, create_time: proc ? proc.create_time : null }], true),
      );
      div.append(force);
    } else {
      const right = document.createElement('span');
      right.textContent = r.status === 'closed' ? `-${mb(r.freed_bytes || 0)}` : '';
      div.append(right);
    }
    box.append(div);
  }

  for (const r of data.rejected || []) {
    const div = document.createElement('div');
    div.className = 'result rejected';
    div.textContent = `${r.pid}: ${r.reason}`;
    box.append(div);
  }

  if (freed > 0) {
    const total = document.createElement('div');
    total.className = 'result closed';
    total.textContent = `Reclaimed ${mb(freed)}`;
    box.prepend(total);
  }
}

function escapeHtml(s) {
  const d = document.createElement('div');
  d.textContent = String(s);
  return d.innerHTML;
}

$('optimize').addEventListener('click', () => optimize(selectedTargets(), false));
poll();
setInterval(poll, POLL_MS);
```

```markdown
# sysmon

A local RAM and process monitor. Claude reads a snapshot file and writes an
advice file. No API call is involved.

## The loop

1. The user runs `run.cmd`. A sampler thread writes `data/snapshot.json`
   every 2 seconds and the dashboard opens at http://127.0.0.1:7777.
2. The user asks Claude to check the laptop.
3. Claude reads `data/snapshot.json`.
4. Claude writes `data/advice.json`.
5. The sidebar picks it up within one 2 second poll.

## Reading the snapshot

`data/snapshot.json` holds `totals` and `facts.groups`. Each group is one
executable with summed RSS across its processes, plus `idle_seconds`,
`rss_trend` in MB per minute, `growing`, and the member `pids`.

Per-process rows with `create_time` are at `GET /api/snapshot`, or run:

    python -c "from monitor.sampler import Sampler; import json; print(json.dumps(Sampler().sample()[:5], indent=2))"

## Writing advice

Write `data/advice.json`:

    {
      "written_at": "2026-11-06T14:22:00",
      "summary": "One or two sentences on what is using the RAM.",
      "targets": [
        {"pid": 4411, "create_time": 1762406400.0, "name": "Teams.exe",
         "reason": "idle 42m, holding 900 MB", "est_mb": 900}
      ],
      "notes": "What you deliberately left alone, and why."
    }

`create_time` is required. Without it the PID reuse guard rejects the target.
Copy it from the snapshot, never invent it.

## Rules

- Never target a process in `BLOCKED_NAMES` (`monitor/constants.py`). The
  server rejects them, but suggesting one wastes the user's time.
- Never target the user's editor or terminal without saying so in `notes`.
- `idle_seconds` equal to the full window means idle for at least that long,
  not exactly that long.
- A high `rss_trend` on a process started seconds ago is startup allocation,
  not a leak. `growing` already applies a 5 minute floor.
- Say what you left alone and why. That is usually more useful than the
  kill list.

## Tests

    python -m pytest

`tests/test_killer.py` spawns and kills real throwaway Python processes.
```

```markdown
# sysmon

A local RAM and process monitor for one Windows laptop, with a sidebar that
renders Claude Code's kill plan behind an Optimize button.

## Running it

    run.cmd

That starts the sampler, serves the dashboard on http://127.0.0.1:7777 and

## How the Claude part works

The dashboard never talks to any model. The sampler writes
`data/snapshot.json`, Claude Code reads that file from disk and writes
`data/advice.json`, and the sidebar polls for it. No API key, no network
request, no token spend beyond the conversation you are already having.

Ask Claude Code "check my laptop" with the monitor running.

## What it will not do

- Kill anything system-critical. `lsass.exe`, `csrss.exe`, `winlogon.exe` and
  the rest of the blocklist are rejected server-side even if the advice file
  names them.
- Kill the terminal running your Claude session, or the monitor itself.
- Force-kill anything on the first press. Optimize sends a close request and
  reports what refused, so an app with unsaved work gets to ask you first.
  Force is a second, per-process click.
- Listen on anything but `127.0.0.1`.
```

## Self-Review

**Spec coverage.** Every spec section maps to a task: 3.1 sampler to Task 5, 3.2 analysis to Task 2, 3.3 safety to Task 3, 3.4 killer to Task 6, 3.5 server to Task 7, 3.6 frontend to Task 8, 3.7 advice contract to Tasks 4 and 9. Section 4 error handling is distributed across the modules that own each case. Section 5 testing is covered by Tasks 2, 3, 4, 6 and 7, with the manual checklist in Task 8 steps 5 and 6.

**Two deliberate deviations from the spec, both recorded here:**

1. The spec's `safety.py` interface described a blocklist of 13 names. The implementation uses 19, adding `svchost.exe`, `ntoskrnl.exe`, `audiodg.exe`, `sihost.exe` and `explorer.exe`. Killing `explorer.exe` removes the taskbar and desktop, and `svchost.exe` hosts most Windows services. Both are survivable rather than fatal, which is exactly why they need blocking: a user would press Optimize without expecting their desktop to vanish.
2. The spec put the advice reader inside `server.py`. It became `monitor/advice.py` so the malformed-file handling is testable without a server.

**Type consistency.** `check_target` and `filter_targets` share the `(target, snapshot, protected)` argument order throughout. `kill_targets` takes snapshot process dicts, which is exactly what `filter_targets` returns as its first element. `build_facts` returns `groups`, which `build_state` annotates with `killable` and the frontend reads under the same name. `create_time` is spelled identically in the sampler, safety, killer, advice contract and frontend.

**One known gap, stated rather than hidden.** The frontend checkbox model is per group, not per PID, so ticking `chrome.exe` targets every Chrome process. That matches how someone thinks about closing an app, and the spec's sidebar mockup shows grouped rows. Killing individual renderers is not reachable from the UI, though the API supports it and Claude's advice can name specific PIDs.
